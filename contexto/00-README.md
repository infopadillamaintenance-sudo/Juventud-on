# Carpeta de contexto — Juventud ON

Esta carpeta contiene todo el contexto necesario para que **Claude Code** (u otro desarrollador/IA) construya la página web / aplicación de **Juventud ON**, el ministerio de jóvenes de la iglesia **Odres Nuevos**.

## Cómo usar esta carpeta

1. Antes de empezar a construir, revisa y completa los campos marcados como `[COMPLETAR]` en los documentos `01` y `02` — son datos reales de la iglesia que aún no se han definido en la conversación.
2. Entrega toda la carpeta (o pégala como contexto) a Claude Code junto con el prompt maestro del archivo `05-prompt-maestro-claude-code.md`.
3. El archivo `03-especificacion-funcional.md` es la especificación técnica/funcional detallada de la plataforma — es el corazón del proyecto.
4. El archivo `04-guia-estilo-visual.md` define el tono visual y de marca.

## Resumen rápido del proyecto

- **Iglesia:** Odres Nuevos (iglesia cristiana)
- **Ministerio:** Juventud ON — el ministerio juvenil de Odres Nuevos
- **Propósito del ministerio:** acercar a los jóvenes a la palabra de Dios y ayudarlos a conocerlo de una forma más juvenil, moderna y cercana a su realidad
- **Producto a construir:** landing page / aplicación web juvenil, dinámica e interactiva, con devocional diario tipo "racha" (streaks), racha de asistencia a los servicios de los viernes, feed social de fotos, anuncios de líderes/capitanes, y una sección de juegos y desafíos en equipo (gamificación)
- **Servicios juveniles:** todos los viernes a las 7:30pm, en Odres Nuevos (Aruba)
- **Instagram:** [@juventud.on](https://www.instagram.com/juventud.on) — 24.7 mil seguidores, comunidad muy activa
- **Tono visual deseado:** moderno, dinámico, enérgico — colores vibrantes/neón, modo oscuro (confirmado también por el estilo real del contenido de Instagram, ver `06-referencias-visuales-instagram.md`)
